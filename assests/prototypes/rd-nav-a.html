      Staleness is derived: the verdict remembers the overlay revision it was computed at and goes stale when the current revision differs. A staged edit bumps that revision even when it turns out to be a no-op. The banner above quotes the current source wording; the design record proposes a narrower “the session’s staged state changed after it was computed” sentence for that reason. Nothing re-runs automatically.

      Scope of this prototype

      • Synthetic data only — the 12 rows, 10 columns, 9 rules and the 2.4 KB export size are hand-written; no dataset was opened or processed.
      • No engine, no network, no telemetry — nothing is queried, uploaded, measured or logged.
      • Built from the source tree at commit bba491a; labels, section purposes, tokens and copy are copied from that tree.
      • Not a shipped UI — this is a design checkpoint (rd-1) for comparison with other alternatives; no product code was changed to produce it.
      • No participant testing has been performed with this file.
      • Numbers are illustrative, and every state change is driven by a control you press.
