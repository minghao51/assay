feat(ew-04d): add the `column-repair` op with undo-by-refold and the engine's conditional repair wrap (U5-first UI-free slice; EW-04D §4.2/§6.2; ADR 0050; D16/D17 probe shapes).

**@assay/domain** — the closed `EditOp` union grows `column-repair` (`{ kind, column, trim?, mapping }`): one authored `trim∘map` value function over a whole textual column, applied per §6.2 forward position-order composition. Plan caps are typed value-free fold refusals, so an invalid plan never enters the log and never reaches the engine: ≤ 500 mapping pairs, ≤ 16 code points in the explicit edge-trim set (never `String.prototype.trim()` — `trimWithCodePoints` is the shared implementation), dead mapping keys (keys carrying trim-set edges can never match the trimmed operand) refused at plan construction, one trim specification per column chain (`repair-trim-mismatch`), and a textual-column gate — the declared type must be `VARCHAR`/`TEXT`/`STRING`, deliberately narrower than the CSV guard's string-like family (`ENUM`/`CHAR` would re-declare as `VARCHAR` under the wrap; `trim()` on anything else is a Binder Error). An applied repair logs one history entry with `inverse: []` and the new `AppliedNote: 'undo-by-refold'` — undo/redo stay pure cursor moves and the state is the exact refold of the active prefix (ADR 0050; the explicit per-kind `OP_UNDO_MODE` table declares refoldable-or-inverse for every kind so a future op cannot skip the declaration; the history walk invariant is narrowed accordingly, the property generator carries a shared repair arm, and the `fold ∘ unfold` walk is narrowed for refold entries). The fold records the value-independent wrap metadata per repair (`RepairStepRecord`: column index, type at apply, liveness snapshot, and per-row masking by later _applied_ `cell-set`/`cell-revert` — logged no-ops never mask). `describeOp` renders the plan shape only (pair count, trim presence) — the mapping payload never enters descriptions (ADR 0025). A pair-free trim-less repair is the typed `repair-identity` no-op.

**@assay/engine-duckdb** — the composer realizes the wrap: window/export/schema gain **stacked projection layers** (one per repair, earliest innermost, additive `O(Σₖ (mₖ + xₖ + 1))` arms — never one-expression nesting, which duplicates the inner wrap and OOMs at three repairs); inserted rows compose via the **D17 literal rewrite** (TypeScript `trim∘map`, `string`/`text`/null kinds only, exactly-once application, surrogate guard on the rewritten output with a repair-specific value-free message — 0 added arms; a non-text value on a surviving repair refuses with a typed error rather than diverge from the engine's own cast). The schema op is the **wrapped DESCRIBE** (D16a: outer projection over `composeSourceSql`, `withRowIds`/`withKey`/`sanitizeCsv` off; bind-only cost; the composed schema now also pays the live-insert branch budget — a pinned behavioural change) and the pending-cast check composes the **split form scoped to repair columns** (D16b: per-row trim + `TRY_CAST` + `IN`-membership; mapped targets are tested **conditionally on actual matches** through an engine-selected constant-relation semi-join — a key no row holds can never fail the check; per-layer exception semantics are preserved exactly: a row excepted at some layers composes its surviving sub-chain, not the raw value — a wrap-as-predicate stays 100–200× more expensive in the existence probe; repair-free columns keep their raw-arm shape byte-for-byte; a textual target composes the provably-empty check). Post-repair casts apply outside the wrap (per-segment cast-chain collapse). The D15 exception cap (`x ≤ 500` per repair) and the published export budget (projected rows × mapping pairs — rows the export actually evaluates: base minus tombstones plus live inserts — over the U4-measured ~4 s corner at 2 M × 500 = 1e9) are pre-apply typed value-free refusals — an honest budget, never claimed as an interrupt. Counts never compose the wrap (values do not affect counts). The overlay wire parser accepts the 9th op kind (bounded structural shape; semantic bounds stay the fold's typed refusals). The package barrel publishes the repair error classes and caps so hosts catch them by identity.

**@assay/web** — compile-forced follow-through of the closed-union growth only: the exhaustive `Record<EditOp['kind'], …>` tables in the pending-change summary carry the new kind (dormant `column repair` label and count entry; no web surface authors repairs in this slice — the ug-23 dormant-label precedent).

**@assay/testing** — the `ConformanceEditOp` mirror type grows the `column-repair` member so it stays type-complete against the domain union (the engine harness's gated `typecheck` assigns `EditOp[]` to it; no conformance scenario composes a repair yet).

No protocol or telemetry change.
