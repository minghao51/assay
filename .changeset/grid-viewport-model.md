feat(m1-5): ship the headless viewport model and evolve the provider contract from its placeholder shape. `GridDataProvider` gains `rowCount()` (a total is metadata, not data — virtualization needs it to size the scroll area) and `fetchRange` now returns an explicit `GridDataPage` (`{ startRow, rows }`) instead of bare `unknown[][]`, so pages carry their origin. The page type is a neutral structural value rather than an Arrow table: the grid keeps zero dependencies (not even type-pinned to the engine's `apache-arrow`), the Arrow→cells projection happens once in the host adapter under ADR 0020's small-projection allowance (visible windows are ≤1000 rows after the engine's clamp), and the model stays Node-testable against plain arrays. New `GridViewportModel` owns visible-range → windowed `fetchRange` requests with overscan, an LRU row cache with in-flight dedup and a hard row bound (default 10k), span chunking (default ≤1000 rows per request, so no unbounded range can be issued), loading/error placeholder semantics with explicit retry, a generation-guarded `refresh()` for future sort/filter epochs, and request/cache counters (`stats`) that make the "never materializes the dataset" guarantee (ADR 0003, architecture §8) observable. React-free, engine-free, DOM-free.
