feat(m4-4): column ops, transformation-history panel, and preview simplification over the edit overlay (ADR 0012). Per-column **rename** and **cast** affordances join the schema panel: rename refuses empty names inline and leaves collisions to the domain's typed `rename-collision` conflict (surfaced as readable text, schema unchanged); cast validates every spelling with the engine's exported `validateEngineTypeExpression` before composing, and then **validates before commit** — the engine's `overlayCastCheck` runs over the pre-cast overlay and a value-level conversion failure is refused with readable text and **no op appended**, while a well-shaped but engine-rejected type is surfaced the same honest way. The check spans an `await`, so the append is guarded by a **history revision**: the pre-cast snapshot is tagged and re-compared at append time, and any concurrent same-table change (cell edit, insert/delete, undo/redo, selective-cursor move) or table switch invalidates the result — the check is re-run against the new state (bounded) or the intent is refused with an honest “the view changed while the cast was being checked; try again”, so a stale `hasNonConvertibleValues:false` can never append a cast over un-checked values. The cast control shows a pending state while a check is in flight. The schema panel now subscribes to the grid model (`useSyncExternalStore`), so **rename/cast re-key its names and type badges** — previously it kept the pre-rename schema and “cast after rename” targeted the old name and failed. (The earlier bounded one-row post-commit probe is removed: it passed whenever row 0 converted and let a broken cast commit over an all-`!` grid; non-cast materialization failures still use the m4-3 rollback + `role="alert"` + Retry path.) Decimal cells now render readably: `DECIMAL(p,s)` (and `HUGEINT`, which Arrow maps to `Decimal(38,0)`) arrive as Arrow's `DecimalBigNum` — a 16-byte `Uint32Array` payload that previously fell through to `<16 bytes>` — and are decoded exactly from the column's precision/scale (`52000.00`, never a lossy float). Boundary (m4-5 carry-over): the decoder is keyed off the column's top-level type, so **decimals nested inside structs/lists still render `<16 bytes>`**; only top-level DECIMAL/NUMERIC/HUGEINT columns are decoded. The new **transformation-history panel** renders the m4-1 log through `describeOp` with each entry's typed outcome and the cursor position, offers selective undo/redo by moving the public cursor (`stateAtCursor` re-folds the prefix, so the resulting grid is consistent by construction), and surfaces the branch-truncation consequence of a rewind (dimmed redo tail + a note) before a new op discards it. **Preview**: the overlay _is_ the preview (every edit is visible immediately and reversible through the history, ADR 0012's staged changes), and a compact pending-changes summary (op counts by kind) makes the staged set legible next to the toolbar — no separate pre-commit staging step. Carry-overs closed: an unchanged draft (temporal or otherwise) on a non-NULL cell is now a **cancel** rather than a spurious dirty no-op edit; a double failure (commit rejected _and_ the restore refresh rejected) is attributed honestly in the alert and paired with a retry affordance so an engine outage cannot leave an unattributed alert over a half-loaded grid; and `edit/overlay-projection.ts` is **removed** — m4-2b made the engine merge folded inserted-row edits itself, so `overlaySnapshot` now hands the raw active ops straight to the engine (the engine's fold is the single source of truth; the m4-3 insert e2e stays green). Tests: column-op validation, pending-summary, pass-through snapshot, commit rollback incl. double failure, a focused decimal128 decoder suite (zero/sign/scale/leading zeros/large/sign extension/offset) plus the sibling byte-type audit (UUID/BLOB/UHUGEINT), a happy-dom app pin for rename/cast validation-before-commit/collision/retry plus the same-table cast race and the schema-panel re-key, and e2e journeys for rename/cast round-trips, cast-after-rename through the panel, both cast failure classes incl. a bad value in a **non-first** row, decimal rendering, the no-op surface, history-panel selective undo/redo + truncation, and the temporal cancel.
