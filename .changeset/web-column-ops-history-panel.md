feat(m4-4): column ops, transformation-history panel, and preview simplification over the edit overlay (ADR 0012). Per-column **rename** and **cast** affordances join the schema panel: rename refuses empty names inline and leaves collisions to the domain's typed `rename-collision` conflict (surfaced as readable text, schema unchanged); cast validates every spelling with the engine's exported `validateEngineTypeExpression` before composing, so an invalid spelling is refused inline with no op, while a well-shaped but engine-rejected type or a legal cast whose values cannot convert rolls back to the previous view with a text-only `role="alert"` (the commit path now probes values with a bounded window read, because `DESCRIBE`/`count(*)` can succeed without evaluating a cast). The new **transformation-history panel** renders the m4-1 log through `describeOp` with each entry's typed outcome and the cursor position, offers selective undo/redo by moving the public cursor (`stateAtCursor` re-folds the prefix, so the resulting grid is consistent by construction), and surfaces the branch-truncation consequence of a rewind (dimmed redo tail + a note) before a new op discards it. **Preview**: the overlay _is_ the preview (every edit is visible immediately and reversible through the history, ADR 0012's staged changes), and a compact pending-changes summary (op counts by kind) makes the staged set legible next to the toolbar — no separate pre-commit staging step. Carry-overs closed: an unchanged draft (temporal or otherwise) on a non-NULL cell is now a **cancel** rather than a spurious dirty no-op edit; a double failure (commit rejected _and_ the restore refresh rejected) is attributed honestly in the alert and paired with a retry affordance so an engine outage cannot leave an unattributed alert over a half-loaded grid; and `edit/overlay-projection.ts` is **removed** — m4-2b made the engine merge folded inserted-row edits itself, so `overlaySnapshot` now hands the raw active ops straight to the engine (the engine's fold is the single source of truth; the m4-3 insert e2e stays green). Tests: column-op validation, pending-summary, pass-through snapshot, commit/verify rollback incl. double failure, a happy-dom app pin for rename/cast/collision/retry, and e2e journeys for rename/cast round-trips, both cast failure classes, the no-op surface, history-panel selective undo/redo + truncation, and the temporal cancel.
