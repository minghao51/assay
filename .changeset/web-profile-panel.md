feat(m2-6): profile panel + distribution charts. The app gains a Profile section for the opened table: a user-triggered "Compute profile" runs the engine's `profile()` op (the m2-5 `engine/profile` FIFO op) and renders per-column statistics — null and distinct counts for every column; min/max/mean/stddev plus the exact p50/p90/p95/p99 quantiles for numeric columns (undefined statistics render honestly as "—"); the categorical top-k list for scalar non-numeric columns; and a graceful degraded display (identity + counts only, no stats or charts) for `other` columns such as STRUCTs. Two dependency-free SVG charts ship from Node-tested geometry modules: a horizontal top-k bar chart (bars scaled to the largest count, engine count-descending/value-ascending order preserved) and a numeric "quantile distribution" strip — proportional segments over the exact engine boundaries min→p50→p90→p95→p99→max, labeled as what it is (the engine delivers quantiles, not row samples, so a true histogram would be dishonest); null quantiles are skipped and annotated, all-null columns get an explanatory empty state instead of a chart. Accessibility follows the disclosure pattern: the panel toggle carries `aria-expanded`/`aria-controls`; the running state is a polite live region (`role="status"`) explaining that the profile shares the engine queue and can take seconds on large files; errors surface readably (`role="alert"`) with a Retry control; both charts carry `role="img"` with complete text alternatives as their accessible names plus per-bar/per-segment `<title>`s and visible text labels. The run reuses the SQL pane's generation guard (`RunGuard` + `runGuarded`, imported not forked) so a late or superseded profile — e.g. after re-opening another table mid-profile — is discarded and never renders (honest limitation, same as the SQL pane: the engine has no op interrupt, so the abandoned profile still occupies the FIFO until it completes). Rendering is data-only: profile outputs, type strings, and engine errors are untrusted content rendered through React text interpolation — no HTML/script execution, and nothing about the data or the file name is logged (ADR 0025). The panel consumes the engine client directly (ADR 0022 precedent recorded with the m1-6 type-string parser: promotion to `@assay/ui` waits for a second consumer).
