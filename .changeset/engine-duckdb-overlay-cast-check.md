feat(m4-4b): add an engine-side cast-conversion check so a host can validate-before-commit a `column-cast` (ADR 0012). New client surface `overlayCastCheck(handle, overlay, { column, targetType })` folds the **pre-cast** overlay state, strictly validates the target type (and rejects unknown effective columns) with the typed `EngineOperationError` before posting, then asks the worker whether any non-NULL value of the effective column cannot convert — a boolean only, never dataset values (ADR 0025). The composed SQL is an early-exit existence check over the existing `composeSourceSql` relation (`SELECT 1 … WHERE col IS NOT NULL AND TRY_CAST(col AS <target>) IS NULL LIMIT 1`), so edits, inserts, tombstones, renames and prior casts are respected; NULLs never count as failures and all-NULL/empty inputs are `false`. Because the domain collapses cast chains to a single direct `CAST(value AS final_type)` at commit (`stepColumnCast`), the check predicates `TRY_CAST` on the **un-cast source value** (`composeSourceSql`'s `valueProjection: 'source'`) rather than on the pre-cast effective projection, so the prediction agrees with the committed cast for chained, edited and inserted values in both directions. The new `engine/overlay-cast-check` protocol request/result rides the query lane per ADR 0040 (a worst-case all-convertible `TRY_CAST` is a full-column scan, exactly the heavy query-class work that must never block grid windows), and a malformed recognised instance is answered with exactly one typed `engine/error`. `@assay/testing` gains the `overlay-cast-check` conformance scenario (all-convertible false; one bad value mid-dataset true — the case the m4-4 1-row probe missed; bad value only in an inserted row true; bad value after a rename true; all-NULL false; a prior cast A→B with a check B→C whose direct base→C cast fails true — the review's chain; a prior-cast-plus-edit same-column case true; a prior cast whose intermediate value fails the target while the direct base cast succeeds false — the symmetric false positive; a no-prior-cast column unaffected by another column's prior cast false; invalid target spelling typed error; unknown column typed error), CLI-1.5.5-derived expectations, and the subject surface to run it.
