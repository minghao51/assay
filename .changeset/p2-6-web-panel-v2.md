feat(p2-6): pipeline panel v2 — grid-native preview, gate statuses, lineage, materialization badges. The landed p-5 panel now consumes the p2-4 runner outcomes and the p2-1 view-as-handle op. **Preview** (arch §15) is per-node, lazy, and on-demand: a materialized data node's relation opens through `client.registerPipelineRelation` and the returned `EngineTableHandle` drives the EXISTING grid model/`DataGrid` renderer and schema surface — the same handle-based registry path a dataset open uses, replacing the p-5 SQL-result detour (no `query()`/`SELECT *` detour). The preview shows the sample rows, the output schema, a schema delta against the node's single input (added/removed/type-changed columns, computed purely), and the p2-3 generated SQL for transform/sql nodes (sanitized like every pipeline-derived string); a session-lifetime disclosure accompanies it. Relations live for the engine session; a run or a new pipeline closes a stale preview. **Gate statuses** (ADR 0035) surface from the p2-4 run results: validate pass/fail with the violated-rule COUNT only (rule values never rendered), diff added/removed/changed counts, and a blocked publish with its missing `requires` gates listed. The run-stopped-at-gate outcome (`status:'gated'`) is now a first-class panel state — distinct from cancel — naming where the run stopped, what completed, the next unexecuted node, the blocked gates, and what a re-run needs; the runner's per-node `materialization` drives the badges (`source`/`view`/`table`/`export`/`gate`), and an export node shows its value-free OPFS artifact path instead of a preview. **Contracts** (C2): each `validate` node gets a parsed contract from an explicit per-node pick (the IR's authored `contract:` path is never resolved in the browser); a run with unbound sources OR contracts is refused up front with every missing node disclosed and zero engine calls, and the runner is driven with the full IR plus host-supplied pure `@assay/validation`/`@assay/diff` compilers so gates execute. **Lineage** (arch §16) is derived from the plan/IR at dataset level (each source's transitive consumers) and node level (inputs, `requires`, consumers), rendered as accessible ordered lists — never a visual graph editor (ADR 0032). Honest empty/error/gated states throughout; the f-2 memo boundary and stable props are preserved. Adds the keyboard-operable v2 gate journey e2e (open → inspect → run → gate failure surfaced → fix → re-run → publish unblocked → preview output) at default and 900px, and dual-scheme axe scans over the preview and gated surfaces with the allowlist still empty. No telemetry (`pipeline_run` stays reserved).
