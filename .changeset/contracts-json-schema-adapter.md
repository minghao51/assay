feat(m5-5): add the JSON Schema adapter (documented draft 2020-12 subset) — `jsonSchemaToContract(input)` converts an object-rooted schema into a contract v1 AST: root `title`/`description` → metadata (title is required; `version` is always 1), `properties` → columns in key order, the four honest type mappings (`string`→VARCHAR, `integer`→BIGINT, `number`→DOUBLE, `boolean`→BOOLEAN; string or single-element array forms), root `required` → required rules (unknown names and duplicates are errors), `enum` → allowed-values (m5-0 entry-kind strictness; an empty enum maps to the real `allowed-values: []` constraint), `minimum`/`maximum` → min/max (inclusive; derived min>max is an error), and `pattern` → a verbatim `regex` rule when the new conservative RE2-subset check (`checkRe2SubsetPattern`, self-contained because contracts cannot import `@assay/validation`) accepts it. Dialect honesty throughout: lookarounds, backreferences, `\u`/`\x`/`\c` escapes, possessive/atomic constructs and ECMA-divergent escapes (`\A`/`\z`/`\a`/`\v`) refuse the pattern as a typed **unsupported-key** error — the authoritative RE2 judgment stays at m5-1 binding time, and nothing is ever approximated; `exclusiveMinimum`/`exclusiveMaximum` are likewise unsupported keys (no honest inclusive mapping). **Every key outside the subset is reported** — collected as typed `JsonSchemaAdapterError`s with an RFC 6901 JSON Pointer path (no line/column: the input is a parsed value, not text), never silently dropped. The adapter is total (never throws — hostile inputs like prototype-spelling keys, throwing getters, unreadable proxies and ±0 are normalized or reported), and every successful conversion is re-verified through `parseContract(serializeContract(…))` (the internal-invariant shield): adapter output always parses as a valid m5-0 contract — pinned by goldens (exact AST + canonical bytes), the per-code unsupported-key matrix, hostile totality probes, and seeded property suites (round-trip seed 20260924, hostile fuzz seed 20260925; no `Math.random`). Pure-package discipline unchanged: no engine, browser, React or `@assay/*` imports.
