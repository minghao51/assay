feat(c02b): web adoption of the atomic whole-list filter capability.

`DuckDbGridProvider` implements the optional `GridDataProvider.replaceFilters(specs)` capability (C01 §5.1): the whole ordered predicate list is replaced in one **all-before-commit** assignment, so a rejection leaves the previously accepted list in effect and observable. Every spec is shape-checked first and only a fully valid list is stored; the list keeps exactly the given order (`filterState` order is what the UI displays and what the engine AND-composes, so nothing is parsed, normalized, sorted or de-duplicated), and `replaceFilters([])` maps to the same internal empty state as `filter(null)` — the engine request bytes are unchanged. The rejection is the provider's own `TypeError`; it carries no phase.

The model is now the **single owner of restoration** (C01 §7), so the three web callers drop their compensating `setFilters(previous)`/clear-and-restore sequences and issue exactly **one** `setFilters` per attempt: `FilterBar.applyList`, `App.applyProfileFilter` (keeping its own attempt/session currency filter) and `useValidationSession.handleFilterToFailures`. Restoration, including the R-C01 reconciliation of superseded runs, happens once inside `GridViewportModel`.

New `apps/web/src/grid/filter-failure.ts` maps the value-free `FilterApplyError.phase` to copy and the one recovery control that phase offers, and every caller shares it: `refused-before-change` keeps the existing framed sentence and the claim that the previous filters are still in effect (the only phase entitled to it); `accepted-reload-failed` says the filters were **applied** but the view could not be reloaded and offers `Retry` (`model.refresh()`) — never a rollback claim, and never the engine/reload text (`model.reloadError` stays diagnostics-only and is never rendered); `restore-failed` reports the honest **unknown** filter state and offers the documented `Clear filters` affordance, which is also the one call that clears `model.filtersUnknown`. All three sentences are single-line and text-only, but they are **not uniformly value-free**, and this changeset does not claim they are: `refused-before-change` deliberately keeps the pre-C02 refusal sentence (the C01 decision to retain the existing framed copy), i.e. the shared `engineErrorMessage('filter', …)` framing, which interpolates the cause's **first line** (`engineErrorLine` keeps the first non-empty line, collapses whitespace, and substitutes a fixed fallback for an empty or opaque-glue message) — so an engine/binder line can appear in that one sentence exactly as it did before C02b. The two new sentences are value-free and never interpolate engine or cause text: `FILTER_RELOAD_FAILED_MESSAGE` and `FILTER_RESTORE_FAILED_MESSAGE` are fixed strings, and neither `error.cause` nor `model.reloadError` (diagnostics only) is rendered for them. Filter drafts stay distinct from accepted filter state (WF-O1 remains separate work: a refused apply keeps the user's typed text instead of overwriting it with the previous list).

A **minor** bump because it adds a capability (the atomic provider path plus the phase-derived failure/recovery surface) without removing anything: providers that still lack `replaceFilters` keep the documented non-atomic legacy sequence, and the grid's own contract, the desktop webview and all other call sites are untouched.

Tests pin the C02b assertions (§9.1 rows 12–14) and the regressions this row owns: provider order/`[]`-equivalence/all-before-commit and one scan per apply (no per-spec scan), one `setFilters` per attempt with no compensating restore for each of the three callers, the phase→copy mapping (the `VIOLENT` sentinel must never reach the two new sentences — `accepted-reload-failed`/`restore-failed` — while the retained `refused-before-change` sentence keeps its pre-C02 first-line cause framing), rapid requests in one tick (loser writes nothing, winner scans once), a superseded accepted A that never becomes effective followed by a newer refused B converging on the published list, accepted-plus-refresh-failure copy, and the legacy double-failure honesty.
