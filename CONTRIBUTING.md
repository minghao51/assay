# Contributing to Assay

The full contributor guide — developer setup, commands, conventions, the ADR
process, dependency rules, and the interim release policy — lives at
[docs/process/contributing.md](docs/process/contributing.md).

Quick start:

```bash
pnpm install
pnpm dev
```

Before implementing a major area (editing, validation, collaboration,
enterprise access, pipelines), check the ADR review gates in
[docs/process/project-start-checklist.md](docs/process/project-start-checklist.md).
