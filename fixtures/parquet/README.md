# Parquet fixtures — generated, not committed

Parquet fixtures (large files, dictionary encoding, unusual logical types,
multi-row-group files, schema drift across partitions) are **generated by
script**, never committed wholesale.

Generation tooling is open decision **D3** in
`docs/product/10-execution-roadmap.md` (candidates: DuckDB CLI script,
small Rust helper, committed tiny binaries for schema-only cases).

This directory will hold:

- the generator script(s),
- checksums,
- a manifest mapping generated files to the tests that use them.
