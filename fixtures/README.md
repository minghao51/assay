# Golden Fixtures

Shared test datasets for unit, property, conformance, and E2E tests.

Policy (from `docs/engineering/04-testing-security-quality.md` §3):

- Every bug involving a specific dataset shape results in a minimal fixture plus a regression test.
- Fixtures must never contain real or sensitive data — synthetic data only.
- Keep fixtures small; large-scale performance datasets are generated by scripts (see `parquet/README.md`), never committed wholesale.

| Category | Contents |
|---|---|
| `csv/` | CSV/TSV, including a v1/v2 pair for diff testing |
| `jsonl/` | NDJSON with nested metadata |
| `nested-json/` | deeply nested structures |
| `parquet/` | generated Parquet (tooling pending — decision D3) |
| `drift/` | dataset pairs with distribution drift |
| `diff/` | canonical pairs for row/schema diff tests |
| `llm/` | chat/eval-style records incl. deliberately malformed ones |
