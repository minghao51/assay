## Queue — validation and contracts (authored 2026-09-19; signed off 2026-09-19 — maintainer pickup; **COMPLETE 2026-09-20 — all seven tasks merged, exit journey green, exact cross-surface agreement proven**; checkpoint 1 (D10) confirmed npm-only; checkpoint 2 resolved by the m5-4 spike → ADR 0041 `@duckdb/node-api` behind the `./node` seam)

**Milestone promise (roadmap §4 + ADRs 0013/0026):** a small native contract format (YAML ↔ canonical
Contract AST) whose rules compile to **deterministic execution plans** (DuckDB SQL in v1) that the
web engine, and the CLI, execute with **identical verdicts** — the same contract behaves consistently
across surfaces (docs 07 §CLI). Exit criteria: a dirty dataset + one contract → web report and CLI
`validate` agree exactly; violations are explorable (sample failures, filter-to-failures) and fixable
in-place via M4 editing (re-validate → clean); six gates green.

**Recorded non-goals for M5 v1 (deferrals, not re-decisions):** cross-field and cross-row rule
expressions (ADR 0013 lists them; deferred to keep v1's plan compiler total and injection-auditable);
adapters beyond JSON Schema (dbt/Pandera/Great Expectations stay backlog); SARIF CI output (v1 ships
human + JSON); suggested repairs (M9 DCR territory); contract format versioning beyond a `v1` field.

**Maintainer checkpoints before dispatch (blocking m5-4 only):**

1. **D10 (CLI distribution)** — default: npm-only (Node ≥ 22, `tsx`) for M5; native packaging
   deferred. Confirm or override.
2. **Node execution backend for the CLI** — candidates: DuckDB-WASM under Node (one engine, one
   version), `@duckdb/node-api` native bindings (new native dep), or shelling to a bundled DuckDB CLI
   binary (not shippable). The m5-4 task begins with a bounded spike and proposes the decision as an
   ADR draft; the orchestrator finalizes it (workers do not write docs). If the maintainer already
   has a preference, record it here before dispatch.
3. **R6 (contract usability spike with real users)** stays a maintainer/manual-track item
   (manual-actions), fed by the m5-0 YAML once merged — not an agent task.
