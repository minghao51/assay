## Queue — dataset diff (authored 2026-09-20; **signed off 2026-09-20 — maintainer pickup treated as sign-off, same pattern as M4/M5**; checkpoints C1–C3 resolved at stated defaults, no override)

**Milestone promise (roadmap §4.6 + docs 01 §4 + ADR 0011):** compare two dataset versions and
get **useful schema/profile change information before full row-level comparison** (docs 07 §Diff
honesty rule) — schema drift, distribution deltas, then key-based row diff (added / removed /
changed rows with changed-column detail) — with **identical results across surfaces**: the same
two files → web panel and CLI `assay diff` agree exactly. Diff reuses the M5 architecture shape:
a pure diff model/plan compiler (`@assay/diff`), a query-lane engine execution with wire
hardening + containment (m5-2 precedent), and byte-pinned cross-surface outputs. Exit criteria:
same two files on both surfaces agree exactly per aspect (asserted, not sampled); findings are
explorable (jump-to-row for A-side rows) and exportable as a sanitized report; six gates green.

**Recorded non-goals for M6 v1 (deferrals, not re-decisions):** statistical p-value tests (KS etc.)
— drift metrics are deterministic (documented bins + thresholds), no significance machinery;
three-way/merge diffs; remote/connector tables (local files only); cross-dataset foreign-key
detection; git-style visual line diffs (M7 surface concern); DCR generation (M9); editing the B
side (B is report content; only A interacts with the grid).

**Checkpoints (defaults unless overridden at sign-off):**

- **C1 — drift metric set:** numeric: PSI + Jensen–Shannon over documented side-A quantile bins
  (epsilon convention documented), standardized mean/variance shift, p50/p90 quantile shifts;
  categorical: total-variation distance over top-k∪other + new/vanished category lists. No
  p-values.
- **C2 — row-diff keys:** explicit user-chosen key columns; inference is a deterministic
  candidate proposal (unique + non-null per profiles, minimal-first, evidence shown) that the
  user confirms in the web UI; CLI `--infer` picks the top candidate and DISCLOSES it in the
  output — never a silent guess.
- **C3 — second-dataset staging (web):** the comparison file is staged via the m4-5 OPFS
  scratch pattern into a typed engine op; the main-grid single-dataset model is unchanged; B-side
  rows are report content (not grid rows); A-side row keys jump in the grid.

**Orchestrator prep at m6-0 dispatch (not a worker responsibility):** eslint purity block for
`packages/diff/**` (allows `@assay/contracts`/`@assay/domain`/`@assay/validation`; forbids
engines/ui/web/cli/react).
