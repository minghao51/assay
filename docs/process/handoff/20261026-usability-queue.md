## 3. Standing notes (decisions and invariants these tasks must respect)

- **Privacy (ADR 0025):** all new copy stays value-free — no filenames, no cell values, no
  dataset contents. Example data (ug-3) uses existing **synthetic** golden fixtures only; never
  author new user-like data. Cell copy (ug-5) is user-initiated and local-only.
- **Editing model (ADR 0012):** ug-8's overlay line and the export staged-count line are copy
  only; export envelopes stay byte-stable. The source is never rewritten.
- **Shell ruling (ADR 0044 / D14 / q-15 placement ruling):** no DOM reordering. ug-22 is
  nav-array-only and must cite the ruling; ug-13/ug-17 add copy inside existing section shells.
- **Single Undo/Redo pair (ux-3 ruling):** ug-6 adds keyboard shortcuts and a badge — never a
  second visible control pair.
- **Engine contracts unchanged:** every row is web-display/session-layer only. No FilterSpec
  grammar change (ug-16/ug-18 compile through the existing pure builder), no engine protocol
  change, no `GridViewportModel` protocol change.
- **Accessibility floor:** dual-scheme axe gates stay green with an empty allowlist; reuse the
  established focus/announcement patterns (ux-2 live region + focus move; uxc-2 pending-gesture
  resolution) rather than inventing new ones.
- **Test pins:** migrate copy pins through `tests/e2e/support/fixtures.ts` first where open-flow
  pins are affected (ug-2/ug-3/ug-14/ug-15); keep the shared helper the single authority.
- **No telemetry** is added by any row (ADR 0037 disclosure would apply otherwise; nothing here
  needs it).
- **arrow/feather (UG-4):** the cheap honest-copy route is authorized here (format list marks
  what the engine accepts); the engine-reads-Arrow route is a separate engine-track decision —
  do not bundle it.
