**Method:** six parallel review lanes (entry points · product · architecture+engineering ·
ADRs · process · reviews/peripheral/governance), every file read end-to-end; every factual
claim verified against the tree, manifests, CI files, and git history — not trusted from the
docs. Scope: 38 files under `docs/` + `README.md`, `AGENTS.md`, `CONTRIBUTING.md`,
`SECURITY.md`, `CHANGELOG.md` + 10 package/fixture READMEs (~55k words). **Zero broken
markdown links repo-wide** — the rot is content-level, not link-level.

**Overall verdict — bimodal by date.** Everything authored or substantially touched after
~2026-09-20 is excellent (`AGENTS.md`, `SECURITY.md`, `engineering/05`, `engineering/08`,
`product/10`+`11`, queue files, ADRs 0040–0042). Everything frozen at the 2026-09-14
bootstrap still speaks from pre-MVP, pre-rename design time — including the repo's front
door. Four systemic diseases: (1) ADR 0039 rename + MVP completion never reached ~10 files;
(2) 3–4-way duplication of commands/layout/rules with no declared single source of truth —
which is _why_ truthfulness sweeps keep missing copies (ar-3 fixed AGENTS/05/docs-README but
had no mandate for `README.md` or `engineering/03`); (3) a changelog double-record pattern
re-bloating `handoff.md` (§9 = 50% of the file one day after the archive split); (4)
point-in-time artifacts without archival banners instructing readers to re-decide settled
law.
